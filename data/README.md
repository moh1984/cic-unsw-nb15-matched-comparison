# Place the dataset CSVs here

The datasets are not redistributed in this repository. Download them from the
sources below and place the CSV files in this directory.

| File expected by the scripts | Source |
|---|---|
| `CIC_NB15.csv` | https://www.unb.ca/cic/datasets/ |
| `unsw_all.csv` | built by concatenating the UNSW-NB15 training and testing partitions from https://research.unsw.edu.au/projects/unsw-nb15-dataset |

See `../docs/reproduce.md` section 1 for the concatenation step and for why it
matters to comparability with prior work.

This directory is listed in `.gitignore`, so its contents are not committed.
